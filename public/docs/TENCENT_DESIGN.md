# 商证的腾讯设计依据

版本：v1.1 · 查阅与实施日期：2026-10-04

## 选择哪个设计体系

这个原型服务商户财务、客服与产品学习者，主要任务是查账、看订单、写交付和核验材料。因此桌面界面采用腾讯 **TDesign** 公开的企业中后台设计规范，按业务任务组织页面。TDesign 允许不同产品在共同基础上定制，并不要求所有腾讯产品长得一样。[TDesign 官方介绍与设计资源](https://github.com/Tencent/tdesign/blob/main/README_zh-CN.md)、[设计价值观](https://static.tdesign.tencent.com/design/values)

**WeUI** 是微信设计团队为微信移动网页提供的界面体系；微信支付的业务规则也不等于所有商户后台必须采用微信绿色。当前原型是桌面工具的响应式版本，沿用同一套任务和状态；未来若做微信内专用移动页面，再按该入口评估 WeUI。[腾讯 WeUI 官方仓库](https://github.com/Tencent/weui)

## 按任务落实，而不是按装饰套模板

| 任务                     | 采用的官方方法                               | 具体实现                                                         |
| ------------------------ | -------------------------------------------- | ---------------------------------------------------------------- |
| 在练习、账单和来源间切换 | 全局导航与区域导航分开；相关模块可用左右布局 | 左侧导航固定，页面内用数据类型选项卡与任务步骤；当前位置清楚     |
| 反复核对不同商户和账期   | 数据查询可按场景选择立即生效                 | 修改商户或日期后刷新同范围金额、订单与回答；取消旧模型结果       |
| 核对多笔交易             | 列表页承载查询与明细查看                     | 表头与行区分，金额右对齐并使用等宽数字；窄屏允许表格横向滚动     |
| 处理复杂异常             | 先看详情，再确认状态流转                     | 展开订单与规则，预览工单；确认复核后才允许本地审核标记           |
| 完成六项交付             | 任务开始前给准备材料，结束后给下一任务引导   | 阶段进度、单选取舍、书面交付、基础检查与下一步；不自动替用户通关 |
| 保存自己的复盘           | 表单有明确标签、输入和结果反馈               | 默认空白笔记，保存时间、未保存提示、上一版本恢复和导出           |

方法来源：[TDesign 中后台整体框架搭建](https://github.com/Tencent/tdesign/blob/bc7fc1dee9c7c2685d765b0931a69d1a52586651/docs/design/offices_zh-CN.md)、[中后台高频任务设计方法](https://github.com/Tencent/tdesign/blob/bc7fc1dee9c7c2685d765b0931a69d1a52586651/docs/design/offices-task_zh-CN.md)

## 金融科技业务中的表达

微信支付官方文档区分支付、退款、查询、通知和账单流程。原型据此保留业务状态与核算口径：支付总额、成功退款、未确认成功退款、手续费和演示账面净额分别展示。金额差异先关联订单，再说明核查步骤；没有银行资金依据时，不用“损失”或“已到账”代替事实。[微信支付商户平台](https://pay.wechatpay.cn/)、[账单开发指引](https://pay.wechatpay.cn/doc/v3/merchant/4013071218)、[退款开发指引](https://pay.wechatpay.cn/doc/v3/merchant/4013071031)

界面文案使用商户、账单、退款状态、核查和工单等具体对象。当前模式、合成数据和人工审核范围放在相应位置；业务操作不反复展示求职宣传或设计术语。完整设计理由放在本说明和产品页，便于面试时解释。

## 对齐范围

本版按腾讯公开体系对齐视觉基础、页面结构和主要交互，保留独立项目身份。腾讯 CDG 内部岗位流程、品牌审批与未公开的产品规范不在公开资料中，不能据此宣称内部认证或完全复刻其生产系统。

验收时核对：桌面与手机阅读、当前步骤、按钮状态、键盘焦点、输入标签、反馈文字、金额列、工单确认及笔记保存。具体结果记录在 `QA_REPORT.md`。
