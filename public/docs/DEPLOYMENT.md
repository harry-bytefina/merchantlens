# 长期作品链接发布

本轮先完成本地作品。用户尚无托管账号；因此不生成虚构网址，不把本机 localhost 写入招聘表。

## 最少步骤：静态作品版

1. 创建 GitHub 或 Vercel 账号，完成平台正常登录。
2. 运行 `npm run build`，确保 `npm test` 全部通过。
3. 将 `dist` 内容发布为静态站点。GitHub Pages 使用静态文件或 Actions 部署；Vercel 的构建命令是 `npm run build`、输出目录为 `dist`。
4. 打开最终 HTTPS 链接检查六个区域、手机布局、文档下载与评测重跑。
5. 在无登录的浏览器检查可访问性后，将最终链接填写到腾讯“相关项目或作品链接”。

静态版默认不调用模型；后端请求失败时继续使用本地证据引擎。招聘评审可以直接操作，不需要输入密钥、注册或提供金融信息。

## 真实模型公网版

当前 Node 后端有本机 Host / Origin 限制，不能直接当作公网服务部署。新增用户身份鉴权、单用户配额、请求限流、日志脱敏与费用封顶后，才考虑托管后端。密钥只放平台服务器环境变量；公开仓库、dist、PDF、CSV 与浏览器源码均不得带密钥。

## 发布前检查

对外文件只能包含合成商户资料。公开包不包含个人身份证、联系方式、原简历、账单密钥、本地 .env 或 node_modules。公开项目标注“独立实习模拟 / 腾讯金融科技业务场景”，不使用腾讯内部项目或正式实习的称谓。
