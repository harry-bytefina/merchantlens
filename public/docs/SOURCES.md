## 4. 使用规则时的注意点

退款状态描述不能被压缩成“处理中就是没扣款”。账单交易金额、资金账单与银行到账是不同信息层。演示合同费率不是微信支付统一费率；生成工单也不是创建真实退款。

检索到官方链接不代表当前结论正确；还要核对规则是否支持该结论、状态是否匹配、商户类型是否适用。模型和检索都不能替代账单证据与人工授权。

## 5. 不可写入申请材料的成果

本项目不支持声称：腾讯内部项目 / 实习；已完成商户访谈；已服务真实客户；真实收入、降本或投诉下降；已经调用混元成功；已经部署公开链接；用户独立手写全部代码。若未来实际完成这些动作，应保留可核验记录并更新版本说明。
