## 后续更新：静态作品版

仓库的 `.github/workflows/pages.yml` 在 `main` 分支推送或手动触发后执行格式检查、测试与构建，再将 `dist` 发布到 GitHub Pages。更新后的部署结果应以相应 Actions 运行记录为准。

1. 修改后运行项目所需检查并生成静态构建。
2. 将经审阅的更改推送至 `main`，查看 Actions 的构建与发布结果。
3. 打开正式 HTTPS 入口，复验六个区域、手机布局、文档下载与评测重跑。
4. 持续补充不同设备和中国大陆网络的访问检查记录，避免将单一环境访问成功写成全面可用性验证。

静态版不托管 Node 模型后端，默认使用本地证据引擎。招聘评审操作演示无需输入密钥、注册或提供金融信息。

## 真实模型公网版

当前 Node 后端有本机 Host / Origin 限制，不能直接当作公网服务部署。新增用户身份鉴权、单用户配额、请求限流、日志脱敏与费用封顶后，才考虑托管后端。密钥只放平台服务器环境变量；公开仓库、dist、PDF、CSV 与浏览器源码均不得带密钥。静态站发布不等于真实混元调用、支付接入或商户试点已经完成。

## 公开内容范围

对外文件只能包含合成商户资料。公开包不包含个人身份证、联系方式、原简历、账单密钥、本地 .env 或 node_modules。公开项目标注“独立实习模拟 / 腾讯金融科技业务场景”，不使用腾讯内部项目或正式实习的称谓。
